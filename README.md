# Fatima V. Malala — Portfolio

Static site (no build step). Open `index.html`, or deploy with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

- `index.html` — content and sections
- `css/style.css` — design tokens at top (`:root`)
- `js/main.js` — GSAP + ScrollTrigger (loaded from cdnjs); the page stays fully readable if GSAP fails to load
- `assets/` — portrait, walking reel (`reel.mp4`), PDF crops
